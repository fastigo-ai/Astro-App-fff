📱 How Real-Time Dynamic Gating Works in AstroBaby

When an admin updates a scheme or grants a subscription, the mobile app reflects it in real time through our unified store and backend services:

1. Schemes Backend API

Endpoint GET /api/v1/subscription/programs feeds the exact program titles, categories, pricing tiers, and inside modules to CourseScreen.tsx and SubscriptionDetailsScreen.tsx.

2. User Locked Gating

Inside the app, ModuleAccessGate checks if the user has subscribed to the program and whether modules like kicks, bump, samvad, or doctor_chat are unlocked.

3. Instant Grant / Revoke

When you grant or revoke a user's scheme from this dashboard, it immediately updates UserJourneysCollection and SubscriptionsCollection, locking or unlocking their access.
